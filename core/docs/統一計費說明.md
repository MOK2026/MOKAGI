# MOKAGI 統一計費系統

## ⚠️ 修改收費標準 → 只需改一個文件！

```
~/.mok/core/mok_price.py
```

改完後 **全系統自動同步**（後端計費 + 前端所有頁面），無需修改其他任何文件。

---

## 架構

```
mok_price.py (唯一價格源)
    │
    ├── 後端: mok_token.py (get_price / price_per_token / cost_of_tokens)
    ├── API:  mok_web.py /api/price (JSON)
    ├── 模板: mok_web.py context_processor → window.MOKAGI_PRICE (所有 Jinja2 模板)
    └── 前端: static/mok_price.js (MokAgiPrice.ready() / formatHKD())
                ├── index.html (消息費用估算)
                ├── webTools/token_billing.html (用量帳單)
                └── project/index.html (收費標準展示)
```

## 修改價格步驟

1. 編輯 `~/.mok/core/mok_price.py`
2. 修改 `MOKAGI_PRICE_HKD_PER_MILLION`（使用費）或 `MOKAGI_SETUP_FEE_HKD`（安裝費）
3. 完成！所有頁面自動更新

## 前端讀取方式

```js
// 等待價格就緒
await MokAgiPrice.ready();
// 讀取
MokAgiPrice.perMillion       // 68
MokAgiPrice.perToken         // 0.000068
MokAgiPrice.setupFee         // 5000
MokAgiPrice.formatHKD(1000)  // "HK$0.0680"
```
