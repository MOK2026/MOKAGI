## 🚀 安裝

**環境需求**:Ubuntu / Debian(建議 22.04+),Python 3.10+,4GB+ RAM。

```bash
# 1. 取得安裝腳本
git clone https://github.com/MOK2026/MOKAGI
cd MOKAGI

# 2. 執行安裝
bash MOKAGI.sh
```

安裝過程會自動:

1. 建立 `~/.mok/` 目錄結構,下載預設設定範本 `env.env`(repo 內的 demo 設定,值為空或佔位,**不是任何人的真實金鑰**);
2. 安裝核心程式、50+ 工具與三種前端;
3. 引導你填入自己的設定:管理員 ID、模型來源、平台金鑰等。

> 安裝完成後,第一件事是把 `env.env` 裡的值換成你自己的。**只有你填進去的金鑰才有效,repo 裡的範本不含任何密鑰。**

## 📅 開放日程（Rollout Schedule）

> **開放前，先補三個洞：金流 · 用戶分離 · 主機安全。**
> 目前 MOKAGI 尚有大量 bug，但資金吃緊、必須盡快開門收人。策略是「**先引流、後收費**」：
> 免費會員先跑起來做 demo 拉客，但每一步開放都有一道**硬卡點**——卡點沒過，該步不開。

| 卡點 | 內容 | 沒過的後果 |
|---|---|---|
| 🔴 金流 | 收款、扣 token、帳單、分潤、退款對帳 | 收不到錢，最後一步卡死 |
| 🔴 用戶分離 | 每人獨立 workspace／記憶／錢包，互不可見 | 一開註冊就等於資安事故 |
| 🔴 主機安全 | 端口、密鑰、HTTPS、WAF、備份 | 開放之日就是被刷爆之日 |

> ⚠️ 共識：這三項目前都是垃圾級狀態。不求一次做完美，只求**依序堵住**——每一步開放前，先把該步的卡點做到「可接受」即可通關；其餘列為並行改善（見文末附註）。

**開放次序：PHASE 1 → 2 → 3**

---

### PHASE 1 · 開放免費會員　`卡點：主機安全`

**目的**：引流 ＋ 比客 demo。用免費用戶把站撐出人氣，同時當成對外示範的活體樣板，讓潛在客戶／金主看到「AI 優化工作流」真的能跑。

- [ ] 遠端登入收緊：停用密碼、改埠、僅金鑰、防爆破
- [ ] 對外端口白名單：只放行 80／443，其餘全關（含 Ollama 端口）
- [ ] 全站強制 HTTPS ＋ HSTS，憑證自動續期
- [ ] 密鑰收權：`.莫氏集團` 等設定檔設 600（僅本人可讀）、不進網站根目錄
- [ ] WAF／速率限制：防爬、防刷、防 CC
- [ ] 備份異地化 ＋ 還原演練（backup／points／restore）
- [ ] 免費用戶每日 token／次數硬上限，防被刷爆成本
- [ ] Demo 模式：唯讀示範帳號，一鍵試玩給客人看
- [ ] 異常告警：登入失敗、資源飆高即時通知

**驗收 DoD**：外部端口掃描無高危暴露；基本滲透測試全數被擋；免費額度無法繞過；主機被刷爆有自動剎停。

---

### PHASE 2 · 開放註冊　`卡點：用戶分離`

**目的**：讓訪客變成「有身分的人」。免費會員可**自建 agent 自己用，也可用其他人的 agent**，註冊是後續收費的唯一入口。

- [ ] 註冊／登入流程 ＋ Email 驗證 ＋ 防機器人
- [ ] 每人獨立 workspace：agent 目錄逐用戶隔離
- [ ] 資料隔離：chat_history／memory／知識庫分庫分權
- [ ] 檔案工具路徑白名單：跨用戶讀寫一律拒絕
- [ ] `/admin exec` 等特權動作綁定角色，非管理員全封
- [ ] 前端只顯示自己的 agent 清單（user.html／側欄）
- [ ] 密碼雜湊（argon2／bcrypt）＋ Session 管理，登出即失效
- [ ] 審計紀錄綁 user_id，誰做了什麼可追
- [ ] 越權測試：A 帳號無法觸及 B 的任何資源

**驗收 DoD**：以兩個帳號交叉測試，A 對 B 的 agent／檔案／對話／記憶／錢包**全部 403**；繞過前端直接打 API 亦被拒。

---

### PHASE 3 · 開放金流　`卡點：金流`

**目的**：開始收錢。會費 ＋ token 雙軌，VIP 還能把自己做的 agent 分給別人用、抽成 token。

- [ ] 接上收款通道（HKD，支援信用卡／電子錢包）
- [ ] 落實定價：68 HKD ＝ 1,000,000 token
- [ ] 會員月費 10 HKD 方案上線
- [ ] VIP 方案：會費 ＋ token；每月送 $11 HKD 等值 token
- [ ] Token 錢包：即時扣費、餘額、帳單明細
- [ ] 分潤機制：VIP 自建 agent 供他人使用 → 分成 token
- [ ] 退款／對帳／收據／稅務處理
- [ ] 防詐：重複扣款、拒付 chargeback、異常金流偵測

**驗收 DoD**：以真實 HKD 完成「付款 → 入帳 → 扣 token → 出帳單 → 退款回沖」全流程一遍無誤；帳目對得上。
