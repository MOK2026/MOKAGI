# MokCs 複製頁面 — 手機版處理機制

## 一、公用手機版 CSS（唯一來源）

| 項目 | 值 |
|---|---|
| 檔案 | `/home/ubuntu/.mok/html/static/mok-mobile.css` |
| 網址 | `/static/mok-mobile.css` |
| 版本 | v1.0 |
| 捷徑 | `/home/ubuntu/.mok/html/project/MokCs/css/mok-mobile.css` → 符號連結指向上面那個檔 |

> 只要改 `static/mok-mobile.css` 一個檔，所有用 `<link>` 的頁面**立即同步生效**。
> （含 `<base href>` 的頁面是內嵌式，需重跑 `refresh` 才會更新。）

## 二、規則（自動判斷）

1. **母站原生有手機版** → 用原生，**完全不動**。
2. **母站沒有手機版** → 注入公用手機版 CSS。

判斷依據（任一成立即視為「原生有手機版」）：
- 頁面內嵌 `@media ... max-width` 斷點
- 使用 bootstrap / tailwind / foundation / bulma / semantic / uikit / webflow … 等響應式框架
- 外連 CSS 檔名含 `responsive` / `mobile` / `rwd`
- 有 `srcset` 響應式圖片
- 頁面載入的**主樣式表**（已排除 fancybox、font-awesome 等外掛）含 `max-width` 斷點

## 三、注入內容

注入在 `</head>` 之前，前後有標記方便還原：

```html
<!-- MOK-MOBILE-CSS v1.0 -->
<meta name="viewport" content="width=device-width, initial-scale=1" data-mok-mobile="1">
<link rel="stylesheet" href="/static/mok-mobile.css" media="all" data-mok-mobile="1">
<!-- /MOK-MOBILE-CSS -->
```

若原頁面**沒有** viewport meta 會自動補上；已有則不加。

**含 `<base href="...">` 的頁面**（相對路徑會被解析到原站）→ 改用 **內嵌 `<style>`**，
把 CSS 內容直接寫進頁面，不受 base 影響。

## 四、工具用法

```bash
cd /home/ubuntu/.mok/html/project/MokCs

# 1) 掃描（只產生報告，不改檔）
python3 tools/mok_mobile_css.py scan                 # 快，不連網
python3 tools/mok_mobile_css.py scan --fetch         # 準，會抓母站 CSS 判斷

# 2) 注入
python3 tools/mok_mobile_css.py apply --file a/某頁.html
python3 tools/mok_mobile_css.py apply --all --fetch  # 只注入真的沒有手機版的頁面

# 3) 還原（位元組級完全還原）
python3 tools/mok_mobile_css.py revert --all
python3 tools/mok_mobile_css.py revert --file a/某頁.html

# 4) 更新已注入的內容（改完 static/mok-mobile.css 後）
python3 tools/mok_mobile_css.py revert --all && python3 tools/mok_mobile_css.py apply --all --fetch
```

其他選項：`--json 檔名`（輸出詳細報告）、`--limit N`（只處理前 N 個）、`--css-url`（自訂 CSS 網址）。

## 五、公用手機版 CSS 做了什麼

只做「防破版 / 能縮放」的安全修正，**不改原站配色字體品牌**：

- 全尺寸：圖片/影片/iframe `max-width:100%`、長字串不撐破、`box-sizing`
- ≤1024px：常見容器（wrapper/container/page…）改為自適應、不加固定寬度
- ≤768px：多欄 grid/row 改單欄、表格可橫向滑動、表單 16px（iOS 不自動放大）、
  導覽可換行、標題縮放、取消 float、任何區塊不超過螢幕寬
- ≤480px：更小的內距與標題
- 輔助 class：`.mok-stack` / `.mok-full` / `.mok-hide-mobile`
