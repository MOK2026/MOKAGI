⚡ MOKAGI Web 聊天接口

一個 script tag，讓任何網站擁有 AI 客服
🔗 github.com/MOK2026/MOKAGI

🚀 30 秒嵌入

在 HTML 的 </body> 前加入這一行：

<script src="https://64071881.xyz/static/api.js"></script>

✅ 完成。頁面右下角會出現 AI 客服氣泡，連接到後端 Agent。

⚠️ 後端需運行 mok_web.py（Socket.IO 伺服器）並在 ~/.mok/agent/ 目錄下配置好 agent.md

⚙️ 配置項總覽

在 api.js 之前設定 window 變數即可覆蓋預設值：

window 變數類型預設值說明

MOKAGI_SERVERstring當前網域Socket.IO 後端地址
MOKAGI_USER_IDstring自動 UUID用戶識別（持久存 localStorage）
MOKAGI_AGENT_ICONstring"🤖"聊天氣泡圖示
MOKAGI_THEMEstring"#4A90D9"主題色
agent_soulstring""AI 性格提示詞
contactstring""AI 無法回答時的緊急聯絡方式

positionstring"bottom-right"氣泡位置
quickLinksarray[]⭐ 快速查詢按鈕（見下方）

🔌 後端接口：mok_web.py

前端透過 Socket.IO 發送 chat_message 事件，後端接收以下欄位：

欄位類型必填說明
messagestring✅用戶輸入的訊息文字
agentstring✅Agent 名稱，對應 ~/.mok/agent/ 目錄
user_idstring用戶唯一識別碼
urlstring用戶當前頁面網址
agent_soulstringAI 性格提示詞
page_urlstring頁面網址（備份欄位）
page_titlestring頁面標題（自動抓取 document.title）
context_filesarray上下文檔案列表，預設 ["agent.md"]

📡 後端回應事件

事件名方向說明
chat_message前端→後端用戶發送訊息
chat_reply後端→前端AI 完整回覆
chat_stream後端→前端⭐ AI 流式回覆（type: "reply" 時累積顯示）

🐍 後端範例

@socketio.on(chat_message)
def handle_chat_message(data):
    user_msg    = data.get(message, ).strip()
    agent_name  = data.get(agent, )
    user_id     = data.get(user_id)
    page_url    = data.get(url, )
    agent_soul  = data.get(agent_soul, )

    # 調用 AI 產生回覆...
    reply = call_ai_agent(agent_name, user_msg, agent_soul)

    # 回傳完整回覆
    socketio.emit(chat_reply, {message: reply})

    # 或使用流式回覆
    for chunk in call_ai_stream(agent_name, user_msg):
        socketio.emit(chat_stream, {
            type: reply,
            content: chunk
        })

🤖 給 LLM 的使用摘要

當用戶問「如何在我的網站嵌入 MOKAGI 聊天」時，以下是最精簡的回答模板：

  1. 在 </body> 前加入 <script src="https://64071881.xyz/static/api.js"></script>
  2. （可選）在 api.js 之前設定 window.MOKAGI_AGENT 指定 Agent 名稱
  3. （可選）設定 window.quickLinks 陣列加入快速查詢按鈕
  4. 後端需運行 Socket.IO 伺服器，監聽 chat_message 事件
  5. Agent 設定檔放在 ~/.mok/agent/<名稱>/agent.md
💡 api.js 會自動收集 document.title、當前 URL，並包裝成增強訊息發送給後端。
