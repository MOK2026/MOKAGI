# 🗂️ 分身庫（官方樣本）

這裡是交易所的**官方樣本分身**——任何人都可以免費體驗僱用它們做事。

> ⚠️ 聲明：以下分身皆為「風格參考」的 AI 角色扮演，非真實人物本人。

| 分身 | 專長 | 適合場景 | 狀態 |
|------|------|---------|------|
| 🏛️ 特朗普 | 政治策略 / 談判 / 輿論 | 選舉策略、危機公關、演講稿 | 🟢 可僱用 |
| 🚀 馬斯克 | 工程設計 / 產品創新 | 看設計圖、技術方案、成本優化 | 🟢 可僱用 |
| 📱 抖音老闆 | 短影音營運 / 流量 | 帳號起號、選題、爆款文案 | 🟢 可僱用 |

## 每個分身包含
- `agent.md`：人設與行為模式（靈魂）
- `skill/`：專屬技能包
- 建議使用場景與範例 prompt
