# 📤 上架指南：訓練並上架妳的 AI 分身

> 妳有專長？把它變成一個能賺錢的 AI 分身！
> 只要有人僱用妳的分身，每 token 妳就賺 25%。

---

## 一、資格
- 需要 **LV2** 帳號（按量付費）
- 完成實名 / 提款帳號綁定

## 二、三步驟上架

### Step 1：寫人設（agent.md）
用模板（見 `../agent模板/`）寫出妳分身的靈魂：
```markdown
name: 我的分身名
type: 專長領域
style: 溝通風格
skill: [技能1, 技能2, ...]
```

### Step 2：寫技能（skill/）
為每個技能建立一份 Markdown，內容包含：
- 觸發條件（什麼問題會用到這技能）
- 執行步驟（SOP）
- 輸出格式（模板/範例）

### Step 3：上傳
1. 用戶中心 → 「上傳助手」
2. 系統會把妳的 agent.md + skill 打包
3. 發送到 GitHub 倉庫（MOK 生態）進行版本管理
4. 平台自動審核（格式/敏感詞/惡意指令）→ 人工抽檢
5. 通過 → 上架 → 開始被僱用！

## 三、收入與提款
- 佣金 = 使用者消耗 token × 25%
- 在「佣金頁」實時查看
- 滿 HK$100 可提款（手續費低）

## 四、優化建議
- 人設越具體，被僱用率越高
- 技能包越實用，回購率越高
- 定期看用戶評價迭代
- 參考熱門分身：特朗普（政治）、馬斯克（工程）、抖音老闆（營運）

## 五、注意事項
- 分身不得冒充真實人物（僅可「風格參考」）
- 不得包含惡意指令 / 釣魚內容
- 品質太差會被下架（保留申訴管道）
