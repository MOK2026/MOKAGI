# 🏛️ AI 分身交易所

> 一個讓「AI 分身」被僱用、被上架、被交易的平台。
> 妳是老闆，全世界最有能力的人都是妳的員工。

---

## 🎯 一句話定位

**AI 分身交易所** = 一個線上的「AI 人才市場」——平台上匯集了各領域的 AI 分身（特朗普、馬斯克、各行業專家…），任何人都可以：

- 👔 **當老闆**：僱用 AI 分身幫妳做事
  - 叫「特朗普」幫妳寫選舉策略
  - 叫「馬斯克」幫妳看設計圖
  - 叫「抖音老闆」幫妳起號
- 💼 **當分身主**：訓練自己的 AI 助手，上架到交易所
  - 有人使用妳的助手 → 妳收到報酬（佣金）

---

## 💰 商業模式（三層收費）

| 等級 | 費用 | 內容 |
|------|------|------|
| 🆓 試用 | 免費 | 每月限量 token，體驗所有分身 |
| 🥉 LV1 | HK$9/月 | 更多 token、完整功能 |
| 🥈 LV2 | 按量付費 | 無限 token + **可上架助手** + 自選 LLM 模型 |

### 成本與利潤模型
- LLM 統一使用 **DeepSeek-V4-Flash**（低成本高效能）
- **平台自營分身**：每 token 平台賺 50%（成本 50% + 平台 50%）
- **用戶上架分身**：每 token 平台賺 25% + 分身主賺 25%（成本 50% + 平台 25% + 分身上架者 25%）
- 免費層每月成本約 HK$1/用戶，LV1 約 HK$4.5/用戶

## 🔄 業務運作流程

```
訪客 → 官網免費試用 → 用量 50%/90% 提示充值 → 100% 停止
     → 註冊充值 → 用戶中心
         ├─ 寫自己的 agent.md / skill
         ├─ 計費頁 / 佣金頁
         ├─ 充值 / 提款
         ├─ 對話記錄（用戶本機保存）
         └─ 上傳助手 → 上架審核 → 開始被僱用賺錢
```
