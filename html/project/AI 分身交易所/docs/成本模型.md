# 📊 成本模型（DeepSeek-V4-Flash）

## 一、模型費率
> ⚠️ 需即時查詢 DeepSeek-V4-Flash 最新費率（此處為估算範例）

假設：
- 輸入：`I` 元 / 百萬 token
- 輸出：`O` 元 / 百萬 token
- 平均單價：`P = (I + O) / 2`

## 二、定價公式

### 官方分身
```
用戶付費 = P × 2
  其中：成本 = P × 1（給 LLM）
        平台利潤 = P × 1（50%）
```

### 用戶上架分身
```
用戶付費 = P × 2
  其中：成本 = P × 1（給 LLM）
        平台利潤 = P × 0.5（25%）
        分身主佣金 = P × 0.5（25%）
```

## 三、免費層成本控制

| 參數 | 數值 |
|------|------|
| 每用戶每月成本上限 | HK$1 |
| 觸發 50% 警告 | 用量達 50% |
| 觸發 90% 警告 | 用量達 90% |
| 停止服務 | 用量達 100% |

## 四、盈虧平衡估算

```
假設月活躍用戶 = 10,000
免費層 7,000 人 × HK$1 = HK$7,000 成本（平台吸收，換數據）
LV1 2,000 人 × HK$9 = HK$18,000 收入（成本 2,000×4.5=HK$9,000 → 毛利 HK$9,000）
LV2 1,000 人（按量，假設平均 HK$30/月）
    → 收入 HK$30,000（成本約 50% → 毛利 HK$15,000）
Token 抽成收入（跨層，估算）≈ HK$20,000

月毛利 ≈ HK$44,000（未計伺服器與人力）
```

## 五、成本優化策略
1. **緩存**：高頻問題快取回覆，減少 LLM 呼叫
2. **模型降級**：簡單任務用更小模型
3. **批量推理**：非同步批次處理
4. **用量分級**：免費層限制高峰時段
5. **自選模型**（LV2）：用戶選貴模型 → 更高抽成
