# 💰 商業模式

## 一、收入來源

### 1. 訂閱收費（平台直接收入）
| 等級 | 月費 | 每月 token 額度 | 主要權限 |
|------|------|----------------|---------|
| 免費試用 | HK$0 | 有限（約 HK$1 成本/用戶） | 使用所有官方分身 |
| LV1 | HK$9 | 較大（約 HK$4.5 成本/用戶） | 完整功能 |
| LV2 | 按量付費 | 無上限 | 自選 LLM + 上架助手 |

### 2. Token 抽成（平台核心收入）
- **官方分身**：使用者每消耗 1 token → 成本 50% + 平台利潤 50%
- **用戶上架分身**：使用者每消耗 1 token → 成本 50% + 平台 25% + 分身主 25%

### 3. 數據價值（長期）
- 免費層收集的對話數據（脫敏後）可作為訓練資料出售
- 匿名化的用戶行為數據 → 洞察報告

## 二、成本結構

| 項目 | 說明 |
|------|------|
| LLM API 成本 | DeepSeek-V4-Flash（低價高效） |
| 伺服器 | 莫氏主機（現有基礎設施） |
| 儲存 | 對話記憶存於莫氏主機 / 用戶本機 |

## 三、單位經濟模型（估算）

```
假設 DeepSeek-V4-Flash 費率：X 元/百萬 token

官方分身：
  收費 = 2X（成本 X + 平台賺 X）

用戶上架分身：
  收費 = 2X（成本 X + 平台 0.5X + 分身主 0.5X）

免費層：每人每月成本約 HK$1（平台自行吸收，換取用戶與數據）
LV1：每人每月成本約 HK$4.5，收費 HK$9 → 毛利率 50%
```

## 四、競爭優勢

1. **低門檻僱用**：不用懂 AI，像叫員工一樣叫分身做事
2. **UGC 分身生態**：任何有專長的人都能上架分身賺錢（長尾效應）
3. **低成本模型**：DeepSeek-V4-Flash 讓單位經濟模型成立
4. **現成基礎設施**：MOK 系統已有 agent 框架、角色模板、記憶系統

## 五、風險與對策

| 風險 | 對策 |
|------|------|
| 模型成本波動 | 動態定價、批量採購 |
| 分身品質參差 | 上架審核 + 用戶評分機制 |
| 版權/肖像問題 | 分身設定為「風格參考」非真實人物 |
| 免費層濫用 | 用量限制 + 驗證碼 + 行為分析 |
